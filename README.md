# LeetCode Practice in Swift

Welcome to my Swift LeetCode practice repository. 👋

This repo is where I practice **Data Structures and Algorithms in Swift** to keep my Swift skills sharp while working mainly with Kotlin day to day.

## 🚀 About This Repository

This repository is dedicated to practicing LeetCode problems in Swift through structured topics, curated problem lists, and daily challenges.

The focus is on:

- Maintaining Swift proficiency
- Keeping a consistent coding habit
- Practicing DSA fundamentals
- Recognizing patterns across similar LeetCode problems
- Writing clean and readable Swift solutions
- Revisiting solutions over time to improve clarity and implementation

## 🎯 Goals

- Keep Swift syntax and standard library usage fresh
- Practice problem solving through hands-on coding
- Strengthen algorithmic thinking
- Review common data structures and patterns
- Build a personal collection of Swift solutions
- Stay comfortable switching between Kotlin and Swift

## 🧠 Practice Approach

For each problem, I try to focus on:

- Understanding the problem clearly
- Identifying edge cases
- Starting from a simple approach
- Finding a cleaner or more efficient solution
- Recognizing the underlying pattern
- Writing readable Swift code
- Reviewing time and space complexity
- Revisiting similar problems to reinforce learning
